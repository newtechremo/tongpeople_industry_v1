## 1. 최초 위험성평가 - 기본 생성 (회귀 테스트)

### 1.1 정상 플로우

**시나리오**: 기본 정보 + 대분류/소분류/위험요인 추가 → 제출

- [ ] 위험성평가 → 최초 평가 등록 클릭
- [ ] **기본 정보**
  - [ ] 현장명, 회사명 자동 입력 확인
  - [ ] 작업 기간 입력
  - [ ] 결재라인 선택
- [ ] **작업 공종 추가**
  - [ ] "작업 공종(대분류) 추가하기" 버튼 클릭
  - [ ] 대분류 선택 (예: 가설전기 설비)
  - [ ] 소분류 선택 (예: 가설전선 설치작업)
- [ ] **위험요인 추가**
  - [ ] 소분류 내 "위험요인 추가" 버튼 클릭
  - [ ] 위험요인 검색/직접입력 (예: 감전 위험)
  - [ ] 개선대책 입력
  - [ ] 작업 기간 입력
  - [ ] **상중하 선택** (예: 상)
- [ ] **제출**
  - [ ] "만들기" 버튼 클릭
  - [ ] 제출 성공 확인
  - [ ] 목록 페이지로 이동

**검증 포인트**:
- ✅ 모든 입력 필드 정상 동작
- ✅ 검증 오류 없음
- ✅ 제출 성공 + 목록 이동

---

### 1.2 필수 필드 검증

**시나리오**: 필수 필드 누락 시 제출 차단

- [ ] 대분류 미선택 시 제출 차단 + 에러 메시지
- [ ] 소분류 미선택 시 제출 차단 + 에러 메시지
- [ ] 위험요인 미입력 시 제출 차단 + 에러 메시지
- [ ] 상중하 미선택 시 제출 차단 + 에러 메시지
- [ ] 개선대책 미입력 시 제출 차단 + 에러 메시지

**검증 포인트**:
- ✅ 모든 필수 필드 검증 동작
- ✅ 에러 메시지가 `validateRiskFactorByMethod`에서 생성됨
- ✅ alert로 섹션별 에러 표시 (예: "소분류 'XXX'의 위험요인 1:\n...")

## 2. 최초 위험성평가 - 중복 가드 (신규 기능)

### 2.1 대분류 중복 선택 차단

**시나리오**: 동일 대분류를 2번 선택하려 할 때 차단

- [ ] 대분류 1개 추가 (예: 가설전기 설비)
- [ ] "작업 공종(대분류) 추가하기" 버튼 클릭
- [ ] **동일 대분류 선택 시도** (예: 가설전기 설비)
- [ ] alert 표시 확인: "이미 선택된 대분류입니다: 가설전기 설비"
- [ ] 선택 취소됨 확인

**검증 포인트**:
- ✅ 중복 대분류 선택 차단
- ✅ alert 메시지 정확
- ✅ 기존 대분류 유지

---

### 2.2 소분류 중복 선택 차단 (체크리스트)

**시나리오**: 동일 대분류 내에서 동일 소분류를 2번 선택하려 할 때 차단

- [ ] 대분류 추가 (예: 가설전기 설비)
- [ ] 소분류 1개 선택 (예: 가설전선 설치작업)
- [ ] 소분류 체크리스트 재오픈
- [ ] **이미 선택된 소분류 체크 시도**
- [ ] alert 표시 확인: "이미 선택된 소분류입니다: 가설전선 설치작업"
- [ ] 체크 취소됨 확인

**검증 포인트**:
- ✅ 중복 소분류 선택 차단
- ✅ alert 메시지 정확
- ✅ 기존 소분류 유지

---

### 2.3 소분류 중복 선택 차단 (커스텀)

**시나리오**: 커스텀 소분류 추가 시 중복 이름 차단

- [ ] 대분류 추가
- [ ] 커스텀 소분류 추가 (예: "특수 작업")
- [ ] 커스텀 소분류 재추가 시도 (동일 이름: "특수 작업")
- [ ] alert 표시 확인: "이미 존재하는 소분류 이름입니다: 특수 작업"
- [ ] 추가 취소됨 확인

**검증 포인트**:
- ✅ 중복 커스텀 소분류 차단
- ✅ alert 메시지 정확
- ✅ 문자열 정규화 (공백/대소문자 무시) 동작 확인

---

### 2.4 위험요인 중복 선택 차단

**시나리오**: 동일 소분류 내에서 동일 위험요인을 2번 선택하려 할 때 차단

- [ ] 대분류 + 소분류 추가
- [ ] 위험요인 추가 (예: "감전 위험")
- [ ] 위험요인 추가 모달 재오픈
- [ ] **동일 위험요인 선택 시도** (예: "감전 위험")
- [ ] alert 표시 확인: "이미 추가된 위험요인입니다: 감전 위험"
- [ ] 추가 취소됨 확인

**검증 포인트**:
- ✅ 중복 위험요인 선택 차단
- ✅ alert 메시지 정확
- ✅ 기존 위험요인 유지

---

### 2.5 문자열 정규화 검증

**시나리오**: 공백/대소문자 차이를 무시하고 중복 감지

- [ ] 대분류 추가 (예: "비계 및 작업발판")
- [ ] 대분류 추가 시도 (예: "  비계  및   작업발판  ") ← 앞뒤/연속 공백
- [ ] 중복 차단 확인
- [ ] 커스텀 소분류 추가 (예: "Special Work")
- [ ] 커스텀 소분류 추가 시도 (예: "special work") ← 대소문자 다름
- [ ] 중복 차단 확인

**검증 포인트**:
- ✅ 문자열 정규화 동작 (trim + 연속 공백 제거 + lowercase)
- ✅ 공백/대소문자 차이를 무시하고 중복 감지

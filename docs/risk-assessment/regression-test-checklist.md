## 1. 수시 위험성평가

### 1.1 생성 (상중하 방식)

**시나리오**: 기본 플로우 - 상중하 방식

- [ ] 위험성평가 → 수시 평가 등록 클릭
- [ ] **1단계: 기본/수시 정보**
  - [ ] 현장명, 회사명 자동 입력 확인
  - [ ] 소속팀 선택 가능
  - [ ] 작업 기간 입력
  - [ ] 결재라인 선택
  - [ ] 수시 평가 정보 (선택): 발생일, 사유 입력
  - [ ] "다음" 버튼 클릭 → 2단계로 이동
- [ ] **2단계: 위험성 산정 방식**
  - [ ] "상중하" 선택
  - [ ] "다음" 버튼 클릭 → 3단계로 이동
- [ ] **3단계: 작업 공종**
  - [ ] 대분류 추가 (예: 비계 및 작업발판)
  - [ ] 소분류 추가 (예: 강관비계)
  - [ ] 조치일 입력
  - [ ] 조치자 1명 이상 선택
  - [ ] 조치확인자 1명 이상 선택
  - [ ] 위험요인 추가
    - [ ] 위험요인 입력 (예: 높은 곳에서의 추락)
    - [ ] 개선대책 입력
    - [ ] 작업 기간 입력
    - [ ] **상중하 선택**: 작은 칩 형태 (h-8) ✓
    - [ ] 상/중/하 중 선택 (예: 상)
- [ ] **제출**
  - [ ] "제출" 버튼 클릭
  - [ ] 검증 통과 확인
  - [ ] 성공 메시지 표시
  - [ ] 목록 페이지로 이동

**검증 포인트**:
- ✅ 3단계 워크플로우 정상 동작
- ✅ 진행률 헤더 표시 ("진행 2/3")
- ✅ 상중하 컴팩트 칩 표시
- ✅ 중복 선택 차단 (대분류/소분류/위험요인)

---

### 1.2 생성 (빈도강도 방식)

**시나리오**: 빈도강도 - 개선 전/후 평가

- [ ] 1단계, 2단계 동일
- [ ] **2단계: 위험성 산정 방식**
  - [ ] **"빈도강도"** 선택
- [ ] **3단계: 위험요인**
  - [ ] 위험요인 추가
  - [ ] **개선 전 평가** (파란색)
    - [ ] 빈도 선택 (1~4)
    - [ ] 강도 선택 (1~5)
    - [ ] 점수 자동 계산 확인
    - [ ] 등급 자동 계산 확인
  - [ ] **개선 후 평가** (초록색)
    - [ ] 빈도 선택 (1~4)
    - [ ] 강도 선택 (1~5)
    - [ ] 점수 자동 계산 확인
    - [ ] 등급 자동 계산 확인
  - [ ] **개선 효과 섹션** 표시
    - [ ] 점수 변화 표시 (예: 20 → 6, -14)
    - [ ] 등급 변화 표시 (예: 상 → 중)
    - [ ] 배지 표시 (개선됨 ✓ 또는 주의 필요 ⚠️)
- [ ] **제출**
  - [ ] 개선 전만 입력 시 제출 차단 확인
  - [ ] 개선 후 > 개선 전 시 경고 확인
  - [ ] 정상 제출 성공

**검증 포인트**:
- ✅ 개선 전/후 2열 그리드 표시
- ✅ 점수/등급 자동 계산
- ✅ 개선 효과 시각화
- ✅ 개선 효과 검증 (개선 후 > 개선 전 차단)

---

### 1.3 상세보기

**시나리오**: 생성한 문서 상세보기

- [ ] 목록에서 생성한 문서 클릭
- [ ] **기본 정보** 표시 확인
  - [ ] 현장명, 회사명, 소속팀
  - [ ] 작업 기간
  - [ ] 결재라인
  - [ ] 수시 평가 정보 (입력했다면)
- [ ] **위험성 산정 방식** 표시 확인
- [ ] **작업 공종** 표시 확인
  - [ ] 대분류 → 소분류 → 위험요인 구조
  - [ ] 조치 정보 (조치일, 조치자, 조치확인자)
  - [ ] **상중하**: 작은 칩 형태 ✓
  - [ ] **빈도강도**: 개선 전/후 2열 그리드 ✓

**검증 포인트**:
- ✅ 모든 입력 정보 정확히 표시
- ✅ 상중하 컴팩트 칩
- ✅ 빈도강도 개선 전/후 표시

---

### 1.4 수정

**시나리오**: 생성한 문서 수정

- [ ] 상세보기에서 "수정" 버튼 클릭
- [ ] 1단계: 작업 기간 변경
- [ ] 3단계: 위험요인 추가
- [ ] 제출 성공 확인
- [ ] 상세보기에서 변경 내용 반영 확인

**검증 포인트**:
- ✅ 수정 모드 진입
- ✅ 기존 데이터 유지
- ✅ 변경 사항 저장

---

### 1.5 엑셀 다운로드

**시나리오**: 엑셀 내보내기

- [ ] 상세보기에서 "엑셀 다운로드" 버튼 클릭
- [ ] 파일 다운로드 확인
- [ ] 엑셀 파일 열어서 데이터 확인
  - [ ] 기본 정보
  - [ ] 작업 공종
  - [ ] 위험요인 (상중하 또는 빈도강도)

**검증 포인트**:
- ✅ 엑셀 생성 성공
- ✅ 데이터 정확성

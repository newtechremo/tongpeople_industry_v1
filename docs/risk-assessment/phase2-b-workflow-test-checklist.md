# Phase 2-B 워크플로우 통합 테스트 체크리스트

**작성일**: 2025-02-20
**목적**: 최초/정기 평가 워크플로우 적용 후 기능 검증
**URL**: http://localhost:5176

---

## 테스트 범위

✅ 최초/정기 평가 워크플로우 (2단계)
✅ 수시와 UI 통일 (컴팩트 칩, Empty State, 레이아웃)
✅ 조치 정보 숨김 (최초/정기는 조치 정보 없음)
✅ 진행률 표시
✅ 중복 가드 (대분류/소분류/위험요인)

---

## 1. 최초 위험성평가 - 워크플로우 생성

### 1.1 기본 플로우

**경로**: 위험성평가 → 최초 평가 등록

#### 섹션 1: 기본 정보
- [ ] 섹션 번호 "1" 표시
- [ ] 제목: "기본 정보"
- [ ] 설명: "현장, 소속팀, 작업기간, 결재라인 정보를 입력합니다."
- [ ] 현장명/회사명 자동 입력 (통사통사현장, (주)통하는사람들)
- [ ] 소속팀 선택 가능
- [ ] 작업기간 입력 (시작일/종료일)
- [ ] 결재라인 선택
- [ ] **위험성 산정 방식 안내 카드** 표시
  - [ ] 주황색 배경 (bg-orange-50)
  - [ ] 텍스트: "위험성 산정 방식"
  - [ ] 설명: "최초 평가는 상중하 방식으로 고정됩니다."
- [ ] "다음" 버튼 클릭
- [ ] 검증 실패 시 alert 표시 (입력 오류)
- [ ] 검증 성공 시:
  - [ ] 섹션 1 완료 상태로 변경 (초록 체크)
  - [ ] 섹션 2로 자동 스크롤
  - [ ] **진행률 배지 업데이트** (1/2)

#### 섹션 2: 작업 공종
- [ ] 섹션 번호 "2" 표시
- [ ] 제목: "작업 공종"
- [ ] 설명: "대분류, 소분류, 위험요인을 입력합니다."
- [ ] "작업 공종(대분류) 추가하기" 버튼 표시
  - [ ] border-dashed 스타일
  - [ ] Plus 아이콘 + 텍스트
- [ ] 대분류 추가
- [ ] 대분류 선택 (예: 가설전기 설비)
- [ ] 소분류 선택 (예: 가설전선 설치작업)
- [ ] 위험요인 추가 버튼 클릭
- [ ] 위험요인 입력 (위험요인/개선대책)
- [ ] **상중하 칩 표시** (수시와 동일)
  - [ ] 작은 칩 (h-8)
  - [ ] grid-cols-[40px,1fr] 레이아웃
  - [ ] 상/중/하 3개 버튼
  - [ ] 선택 시 색상 변경 (빨강/주황/초록)
- [ ] "다음" 버튼 클릭
- [ ] 검증 성공 시:
  - [ ] 섹션 2 완료 상태로 변경
  - [ ] **진행률 배지 업데이트** (2/2)
  - [ ] "만들기" 버튼 활성화

#### 제출
- [ ] "취소" 버튼 표시 (회색)
- [ ] "만들기" 버튼 표시 (주황 그라데이션)
- [ ] 섹션 완료 전에는 버튼 비활성화 (disabled)
- [ ] 모든 섹션 완료 후 버튼 활성화
- [ ] "만들기" 클릭 시 제출 성공
- [ ] 목록 페이지로 이동

---

### 1.2 진행률 표시

- [ ] 페이지 제목 옆에 진행률 배지 표시
- [ ] 초기: "진행 0/2"
- [ ] 섹션 1 완료: "진행 1/2"
- [ ] 섹션 2 완료: "진행 2/2"
- [ ] 배지 스타일: 주황색 배경, 작은 크기

---

### 1.3 중복 선택 차단

#### 대분류 중복
- [ ] 대분류 1개 추가 (예: 가설전기 설비)
- [ ] 대분류 2개 추가
- [ ] 동일 대분류 선택 시도
- [ ] alert 표시: "이미 선택된 대분류입니다"
- [ ] 선택 취소됨

#### 소분류 중복
- [ ] 소분류 1개 선택 (예: 가설전선 설치작업)
- [ ] 소분류 모달 재오픈
- [ ] 이미 선택된 소분류는 체크박스 비활성화
- [ ] 또는 선택 시 alert 표시

#### 위험요인 중복
- [ ] 위험요인 1개 추가 (예: 감전 위험)
- [ ] 위험요인 추가 모달 재오픈
- [ ] 동일 위험요인 선택 시도
- [ ] 기존 위험요인 목록에서 제외됨
- [ ] 또는 선택 시 alert 표시

---

### 1.4 섹션 재수정

#### 완료된 섹션 클릭
- [ ] 섹션 1 완료 후 헤더 클릭
- [ ] 섹션 펼쳐짐 (재수정 가능)
- [ ] 작업기간 변경
- [ ] "다음" 버튼 다시 클릭
- [ ] 변경사항 저장 + 다음 섹션으로 이동

#### 이전 버튼
- [ ] 섹션 2에서 "이전" 버튼 클릭
- [ ] 섹션 1로 이동
- [ ] 섹션 1 자동 펼쳐짐

## 2. 최초 위험성평가 - 상세보기

**경로**: 위험성평가 → 목록 → 문서 클릭

### 2.1 기본 정보
- [ ] 현장명, 회사명 표시
- [ ] 작업기간 표시
- [ ] 결재라인 표시
- [ ] 위험성 방식 표시: "상중하 방식"

### 2.2 작업 공종
- [ ] 대분류 → 소분류 → 위험요인 구조
- [ ] 위험요인별로:
  - [ ] 위험요인명 표시
  - [ ] 개선대책 표시
  - [ ] 작업기간 표시
  - [ ] **상중하 칩 표시** (컴팩트)
    - [ ] h-8 작은 칩
    - [ ] 선택된 값만 색상 표시
    - [ ] 미선택 칩은 회색

### 2.3 조치 정보
- [ ] **조치 정보 영역 없음** (최초/정기는 조치 정보 없음)
- [ ] 소분류 아래에 조치일/조치자/조치확인자 표시 안 됨

---

## 3. 정기 위험성평가 - 동일 플로우

**경로**: 위험성평가 → 정기 평가 등록

- [ ] 최초와 동일한 워크플로우
- [ ] 위험성 산정 방식 안내: "**정기** 평가는 상중하 방식으로 고정됩니다"
- [ ] 나머지 동일

---

## 4. 수시 위험성평가 - 비교 확인 (회귀)

**경로**: 위험성평가 → 수시 평가 등록

### 4.1 워크플로우
- [ ] 3단계: 기본/수시 정보 → 위험성 방식 → 작업 공종
- [ ] 진행률: "진행 0/3", "진행 1/3", "진행 2/3", "진행 3/3"
- [ ] 수시 정보 입력 (발생일, 사유)
- [ ] 위험성 방식 선택 가능 (상중하 / 빈도강도)

### 4.2 조치 정보
- [ ] 소분류별 조치 정보 입력
  - [ ] 조치일
  - [ ] 조치자 선택
  - [ ] 조치확인자 선택

### 4.3 상세보기
- [ ] 조치 정보 영역 표시 (주황색 테두리)
- [ ] 조치일/조치자/조치확인자 표시

---

## 5. UI 통일 확인

### 5.1 상중하 칩 (최초/정기/수시 공통)
- [ ] 높이: h-8 (작은 칩)
- [ ] 레이아웃: grid-cols-[40px,1fr]
- [ ] 레이블 위치: 왼쪽 (40px)
- [ ] 칩 위치: 오른쪽 (1fr, grid-cols-3)
- [ ] 색상:
  - [ ] 상: 빨강 (border-red-500 bg-red-100 text-red-700)
  - [ ] 중: 주황 (border-orange-500 bg-orange-100 text-orange-700)
  - [ ] 하: 초록 (border-green-500 bg-green-100 text-green-700)

### 5.2 빈도강도 (수시만)
- [ ] 개선 전 (파란색) / 개선 후 (초록색) 2열 그리드
- [ ] 빈도: grid-cols-4 (1-4)
- [ ] 강도: grid-cols-5 (1-5)
- [ ] 점수/등급 자동 계산 표시

### 5.3 Empty State (공통)
- [ ] "작업 공종(대분류) 추가하기" 버튼
- [ ] border-2 border-dashed border-gray-300
- [ ] hover 시 border-orange-500 bg-orange-50

## 6. 크로스 체크 (최초/정기/수시)

### 6.1 생성
- [ ] 최초: 2단계 워크플로우, 상중하 고정, 조치 정보 없음
- [ ] 정기: 2단계 워크플로우, 상중하 고정, 조치 정보 없음
- [ ] 수시: 3단계 워크플로우, 방식 선택, 조치 정보 있음

### 6.2 상세보기
- [ ] 최초: 상중하 칩, 조치 정보 없음
- [ ] 정기: 상중하 칩, 조치 정보 없음
- [ ] 수시(상중하): 상중하 칩, 조치 정보 있음
- [ ] 수시(빈도강도): 개선 전/후 그리드, 조치 정보 있음

### 6.3 진행률
- [ ] 최초: 2단계 (0/2 → 1/2 → 2/2)
- [ ] 정기: 2단계 (0/2 → 1/2 → 2/2)
- [ ] 수시: 3단계 (0/3 → 1/3 → 2/3 → 3/3)

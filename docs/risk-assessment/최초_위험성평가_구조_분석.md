## 1. 개요

### 1.1 기본 철학

**"Category → Subcategory → RiskFactor 3단계 구조"**

```
최초 위험성평가
├── 기본 정보 (BasicInfoSection)
├── 작업 공종 (Category) [동적 추가]
│   ├── 대분류 선택
│   └── 소분류 체크리스트 (Subcategory) [동적 추가]
│       └── 위험요인 카드 (RiskFactor) [동적 추가]
└── 제출
```

### 1.2 핵심 특징

| 특징 | 설명 |
|------|------|
| **중첩 구조** | Category > Subcategory > RiskFactor 3단계 |
| **동적 추가** | 각 단계에서 무제한 추가 가능 |
| **인라인 검증** | 제출 시 중첩 for문으로 전체 검증 |
| **상태 관리** | useState로 복잡한 중첩 배열 관리 |
| **ID 생성** | 클라이언트에서 임시 ID 생성 (`temp-${timestamp}-${counter}`) |

## 3. 데이터 타입

### 3.1 TypeScript Interface

```typescript
// 위험요인 (가장 하위)
interface RiskFactor {
  id: string;                              // 임시 ID (temp-{timestamp}-{counter})
  factor: string;                          // 위험요인 내용
  level: 'HIGH' | 'MEDIUM' | 'LOW' | null; // 위험성 수준 (상/중/하)
  improvement: string;                     // 개선대책
  workPeriodStart: string;                 // 작업 시작일 (YYYY-MM-DD)
  workPeriodEnd: string;                   // 작업 종료일
}

// 소분류
interface Subcategory {
  id: number;                              // 소분류 ID (DB ID 또는 임시 ID)
  name: string;                            // 소분류명
  isCustom?: boolean;                      // 사용자 정의 여부
  riskFactors: RiskFactor[];               // 위험요인 배열
}

// 대분류 (Category)
interface Category {
  id: string;                              // 임시 ID (클라이언트 생성)
  categoryId: number | null;               // 대분류 ID (DB ID)
  categoryName: string;                    // 대분류명
  subcategories: Subcategory[];            // 소분류 배열
}

// 제출 데이터
interface InitialAssessmentPayload {
  siteName: string;
  companyName: string;
  approvalLineId: string | null;
  workPeriodStart: string;
  workPeriodEnd: string;
  categories: Category[];                  // 대분류 배열
}
```

```typescript
// 1. Category 추가
const handleAddCategory = () => {
  setCategories([
    ...categories,
    {
      id: generateId(),
      categoryId: null,
      categoryName: '',
      subcategories: [],
    },

// 2. Category 수정 (map 사용)
const handleCategoryChange = (categoryId: string, newCategoryId: number, newCategoryName: string) => {
  setCategories(
    categories.map((cat) =>
      cat.id === categoryId
        ? { ...cat, categoryId: newCategoryId, categoryName: newCategoryName }
        : cat
    )
  );
};

// 3. Subcategory 추가 (중첩 map)
const handleSubcategoryToggle = (categoryId: string, subcategoryIds: number[]) => {
  setCategories(
    categories.map((cat) => {
      if (cat.id !== categoryId) return cat;

      const existingSubs = cat.subcategories.filter((sub) =>
        subcategoryIds.includes(sub.id)
      );

      const newSubIds = subcategoryIds.filter(
        (id) => !cat.subcategories.find((sub) => sub.id === id)
      );

      const newSubs: Subcategory[] = newSubIds.map((id) => ({
        id,
        name: getMockSubcategoryName(id),
        riskFactors: [],
      }));

      return {
        ...cat,
        subcategories: [...existingSubs, ...newSubs],
      };
    })
  );
};

// 4. RiskFactor 추가 (3단계 중첩 map!)
const handleSelectRiskFactors = (factors: { factor: string; improvement: string }[]) => {
  if (!activeCategory || !activeSubcategory) return;

  setCategories(
    categories.map((cat) => {
      if (cat.id !== activeCategory) return cat;

      return {
        ...cat,
        subcategories: cat.subcategories.map((sub) => {
          if (sub.id !== activeSubcategory) return sub;

          const newFactors: RiskFactor[] = factors.map((f) => ({
            id: generateId(),
            factor: f.factor,
            level: null,
            improvement: f.improvement,
            workPeriodStart,
            workPeriodEnd,
          }));

          return {
            ...sub,
            riskFactors: [...sub.riskFactors, ...newFactors],
          };
        }),
      };
    })
  );
};

// 5. RiskFactor 필드 업데이트 (3단계 중첩 map)
const handleUpdateRiskFactor = (
  categoryId: string,
  subcategoryId: number,
  factorId: string,
  field: string,
  value: string
) => {
  setCategories(
    categories.map((cat) => {
      if (cat.id !== categoryId) return cat;

      return {
        ...cat,
        subcategories: cat.subcategories.map((sub) => {
          if (sub.id !== subcategoryId) return sub;

          return {
            ...sub,
            riskFactors: sub.riskFactors.map((factor) =>
              factor.id === factorId ? { ...factor, [field]: value } : factor
            ),
          };
        }),
      };
    })
  );
};
```

## 8. 검증 로직

### 8.1 제출 시 검증 (인라인 alert)

```typescript
const handleSubmit = (e: React.FormEvent) => {
  e.preventDefault();

  // 1. 대분류 최소 1개
  if (categories.length === 0) {
    alert('최소 1개 이상의 작업 공종을 추가해주세요.');
    return;
  }

  // 2. 각 대분류 검증
  for (let i = 0; i < categories.length; i++) {
    const category = categories[i];

    // 2-1. 대분류 선택 여부
    if (!category.categoryId) {
      alert(`대분류${i + 1}를 선택해주세요.`);
      return;
    }

    // 2-2. 소분류 최소 1개
    if (category.subcategories.length === 0) {
      alert(`대분류${i + 1} (${category.categoryName})에 최소 1개 이상의 소분류를 선택해주세요.`);
      return;
    }

    // 3. 각 소분류 검증
    for (let j = 0; j < category.subcategories.length; j++) {
      const subcategory = category.subcategories[j];

      // 3-1. 위험요인 최소 1개
      if (subcategory.riskFactors.length === 0) {
        alert(`소분류 "${subcategory.name}"에 최소 1개 이상의 위험요인을 추가해주세요.`);
        return;
      }

      // 4. 각 위험요인 검증
      for (let k = 0; k < subcategory.riskFactors.length; k++) {
        const factor = subcategory.riskFactors[k];

        // 4-1. 위험요인 입력 여부
        if (!factor.factor.trim()) {
          alert(`소분류 "${subcategory.name}"의 위험요인 ${k + 1}번째 항목에 위험요인을 입력해주세요.`);
          return;
        }

        // 4-2. 위험성 수준 선택 여부
        if (!factor.level) {
          alert(`소분류 "${subcategory.name}"의 위험요인 "${factor.factor}"의 위험성 수준을 선택해주세요.`);
          return;
        }

        // 4-3. 개선대책 입력 여부
        if (!factor.improvement.trim()) {
          alert(`소분류 "${subcategory.name}"의 위험요인 "${factor.factor}"의 개선대책을 입력해주세요.`);
          return;
        }
      }
    }
  }

  // 모든 검증 통과 → 제출
  onSubmit({
    siteName,
    companyName,
    approvalLineId: selectedApprovalLine?.id || null,
    workPeriodStart,
    workPeriodEnd,
    categories,
  });
};
```

## 12. 핵심 패턴 요약

### 12.1 3단계 중첩 구조

```
Category (대분류) - 동적 배열
└── Subcategory (소분류) - 동적 배열
    └── RiskFactor (위험요인) - 동적 배열
```

### 12.2 불변성 업데이트 (Immutable Update)

```typescript
// Level 1: Category 업데이트
setCategories(categories.map(cat =>
  cat.id === targetId ? { ...cat, field: value } : cat
));

// Level 2: Subcategory 업데이트
setCategories(categories.map(cat => {
  if (cat.id !== categoryId) return cat;
  return {
    ...cat,
    subcategories: cat.subcategories.map(sub =>
      sub.id === targetId ? { ...sub, field: value } : sub
    ),
  };
}));

// Level 3: RiskFactor 업데이트
setCategories(categories.map(cat => {
  if (cat.id !== categoryId) return cat;
  return {
    ...cat,
    subcategories: cat.subcategories.map(sub => {
      if (sub.id !== subcategoryId) return sub;
      return {
        ...sub,
        riskFactors: sub.riskFactors.map(factor =>
          factor.id === factorId ? { ...factor, [field]: value } : factor
        ),
      };
    }),
  };
}));
```

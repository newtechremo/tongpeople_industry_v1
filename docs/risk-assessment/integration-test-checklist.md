## 1. 수시 위험성평가 - 생성 테스트

### 1.1 워크플로우 테스트 (상중하)

**경로**: 위험성평가 → 수시 평가 등록

#### 검증 포인트: generateId() 함수

- [ ] 대분류 추가 시 고유 ID 생성 확인
  - [ ] 대분류 2개 이상 추가
  - [ ] 각 대분류의 ID가 고유한지 확인 (중복 없음)
  - [ ] ID 형식: `temp-[timestamp]-[counter]`

- [ ] 위험요인 추가 시 고유 ID 생성 확인
  - [ ] 동일 소분류에 위험요인 3개 추가
  - [ ] 각 위험요인의 ID가 고유한지 확인

#### 검증 포인트: formatDateInputValue() 함수

- [ ] 작업기간 입력 필드 확인
  - [ ] 시작일 기본값이 오늘 날짜인지 확인 (YYYY-MM-DD 형식)
  - [ ] 날짜 포맷이 올바른지 확인 (예: 2025-02-20)

#### 검증 포인트: addMonths() 함수

- [ ] 종료일 기본값 확인
  - [ ] 종료일이 시작일 + 1개월인지 확인
  - [ ] 날짜 계산이 정확한지 확인

#### 전체 플로우 테스트

- [ ] 1단계: 기본/수시 정보 입력
  - [ ] 작업기간 자동 입력 확인
  - [ ] "다음" 버튼 클릭 → 2단계 이동

- [ ] 2단계: 위험성 산정 방식
  - [ ] "상중하" 선택
  - [ ] "다음" 버튼 클릭 → 3단계 이동

- [ ] 3단계: 작업 공종
  - [ ] 대분류 추가 (예: 비계 및 작업발판)
  - [ ] 소분류 추가 (예: 강관비계)
  - [ ] 위험요인 추가
    - [ ] 위험요인 입력 (예: 높은 곳에서의 추락)
    - [ ] 개선대책 입력
    - [ ] 작업 기간 자동 입력 확인
    - [ ] 상중하 선택 (예: 상)
  - [ ] 조치 정보 입력
    - [ ] 조치일 입력
    - [ ] 조치자 선택
    - [ ] 조치확인자 선택

- [ ] 제출
  - [ ] "제출" 버튼 클릭
  - [ ] 성공 메시지 표시
  - [ ] 목록 페이지로 이동
